01 / ИнтерфейсTUI · CLI

Настоящий терминал

Многострочный ввод, автодополнение команд, история и потоковый вывод инструментов. Агента можно перебить и перенаправить в любой момент.

❯ почему упал ночной деплой? ┊ 📚 skill fly-deploy ┊ 💻 $ fly logs --since 8h ┊ 💻 $ pytest -q 48 passed
02 / Расписаниеcron

Работает, пока вы спите

Встроенный планировщик. Задачу описываете словами, результат приходит в нужный чат: отчёты, бэкапы, проверки.

0 9 * * 1-5 сводка в Telegram every 2h логи прода 0 3 * * * бэкап базы → Slack
03 / Делегированиеdelegate_task

Субагенты в параллель

Независимые части работы уходят изолированным исполнителям. Для нескольких профилей есть общая доска задач Kanban.

hermes ├─ исследовать API ├─ написать миграцию └─ обновить документацию
04 / Среды6 бэкендов

Не привязан к ноутбуку

Локально, в Docker, по SSH, в Singularity, Modal или Daytona. Серверные среды засыпают в простое и почти ничего не стоят.

terminal.backend local docker ssh singularity modal daytona
05 / Расширенияskills · MCP · plugins

Растёт навыками

Новые возможности приходят как навыки, MCP-серверы и плагины. Ядро остаётся компактным, а кэш промпта не сбрасывается посреди разговора.

skills agentskills.io mcp любой сервер plugins хуки и команды profiles изоляция
