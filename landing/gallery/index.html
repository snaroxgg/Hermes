Информация для посетителей

Как попасть
на выставку

  1. I
    Установите

    Скрипт сам поставит Python 3.11, Node.js, ripgrep и ffmpeg.

  2. II
    Настройте

    Мастер hermes setup спросит модель, инструменты и мессенджеры.

  3. III
    Говорите

    Запустите hermes в терминале или напишите боту.

$ curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash
  uv · python 3.11 · node · ripgrep · ffmpeg  готово

$ hermes setup
  провайдер: Nous Portal ✓  шлюз: Telegram ✓

$ hermes
