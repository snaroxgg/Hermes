Возможности

Сделан для работы,
а не для демо

Всё ниже уже есть в открытом репозитории и настраивается командами hermes setup и hermes tools.

01 · Интерфейс

Настоящий терминал

TUI с многострочным вводом, автодополнением команд и потоковым выводом инструментов. Перебить агента и дать новое указание можно в любой момент.

❯ почему упал ночной деплой? ┊ 📚 skill fly-deploy ┊ 💻 $ fly logs -a shop --since 8h ┊ 🔧 patch migrations/0042_orders.sql ┊ 💻 $ pytest tests/db -q 48 passed
02 · Расписание

Работает, пока вы спите

Встроенный планировщик. Задачу описываете словами, результат приходит в нужный чат.

0 9 * * 1-5Сводка по задачам и почте в Telegram
every 2hПроверить логи прода и сообщить об ошибках
0 3 * * *Ночной бэкап базы и отчёт в Slack
03 · Делегирование

Субагенты

Независимые части работы уходят изолированным исполнителям и идут параллельно.

hermes ├─ исследовать API ├─ написать миграцию └─ обновить документацию
04 · Среды

Не только ноутбук

Серверные среды засыпают в простое и почти ничего не стоят между сессиями.

localdockersshsingularitymodaldaytona
05 · Безопасность

Под вашим контролем

Опасные команды ждут подтверждения, чужие сообщения отсекаются привязкой аккаунта, а запуск можно изолировать в контейнере.

06 · Расширения

Растёт навыками, а не раздуванием ядра

Новые возможности приходят как навыки, MCP-серверы и плагины. Ядро остаётся компактным, а кэш промпта не сбрасывается посреди разговора.

Навыкистандарт agentskills.io
MCPлюбой MCP-сервер
Плагиныинструменты, хуки, команды

Установка

Две минуты
до первого разговора

  1. УстановитеСкрипт сам поставит Python 3.11, Node.js, ripgrep и ffmpeg.
  2. НастройтеМастер hermes setup спросит модель, инструменты и мессенджеры.
  3. ГоворитеЗапустите hermes в терминале или напишите боту.
$ curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash  uv · python 3.11 · node · ripgrep · ffmpeg  готово $ hermes setup  провайдер: Nous Portal  ✓   шлюз: Telegram  ✓ $ hermes☤ Hermes Agent на связи. Чем займёмся?❯
